# 한국어 친구 · 传智杯 Vibe Coding 赛道技术说明

版本：2026-10-26  
项目：한국어 친구（韩语学习智能体，网页版 + 微信小程序）

## 1. 项目概述

한국어 친구是一款面向中文母语韩语学习者的 AI 口语练习工具。产品把自由对话、即时纠错、薄弱点追踪、间隔复习和口语跟读放进同一条学习流程。它的目标不是只给出一轮聊天回复，而是把练习产生的学习证据用于后续训练。

项目提供 Vue 3 网页版和微信原生小程序，后端使用 Node.js 与 Express。没有配置 AI 服务时，系统仍可通过演示模式体验主要页面和预置学习流程；配置模型后启用 AI 对话、图片理解、语音识别、语音合成等能力。

网页版新增无需登录的 `/project` 作品介绍页，评审可以先了解项目定位、学习闭环、功能和架构，再决定是否进入交互体验。

## 2. 面向用户的问题

初学者常遇到四个问题：不知道从什么话题开口；表达出错后缺少可理解的解释；同类错误容易反复出现；练习进度难以转化为具体的下一步计划。产品针对这些问题提供：

- 按学习目标、TOPIK 水平和薄弱点组织的情景口语练习。
- 对话纠错及错误记录，将重复出现的问题带入后续训练。
- 生词本与间隔复习调度，帮助把一次性讲解转成复习任务。
- 发音跟读、语音识别和 AI 反馈，并记录发音练习趋势。
- 图片教材识别、歌曲歌词逐句学习和每日名句等多种练习入口。

## 3. 功能与演示路径

| 模块 | 能力 | 演示建议 |
|---|---|---|
| 今日首页 | 展示训练重点、能力维度、连续学习和到期复习；分数来自已有学习记录 | 先查看空档案状态，再完成对话后回到首页看数据变化 |
| AI 对话 | 多模式、多角色和情景练习；流式回复；基于学习状态调整难度 | 选择一个日常场景，用韩语回答并观察纠错 |
| 学习记忆 | 记录错误、生词和复习队列；将近期弱项传入下一轮训练 | 展示“错误出现 → 记录 → 后续复练”的闭环 |
| 发音训练 | 标准音朗读、录音跟读、ASR 识别和反馈 | 播放一个目标句，录制跟读并查看评分依据 |
| 教材图片 | 上传图片，执行图像归一化、文字提取和内容讲解 | 使用清晰、无个人信息的韩语教材照片 |
| 歌曲学习 | 歌词逐行分析、词汇收藏和复习 | 选择一首已支持歌曲，展示逐句理解与收藏 |
| 演示模式 | 使用预置剧本体验测试、定级、纠错、错误记忆、掌握和情景复盘 | 从首页进入“演示模式”，按 3 分钟流程讲解 |

建议的 5–8 分钟录屏结构：项目定位（30 秒）→ 对话纠错闭环（2 分钟）→ 发音或教材识别（1 分钟）→ 学习档案与能力趋势（1 分钟）→ 技术架构及一段真实 AI 协同迭代（至少 2 分钟）。录屏前检查麦克风授权、网络和后端服务状态，并使用虚构学习数据。

## 4. 关键设计

### 4.1 学习闭环

系统通过 `server/src/agent.js` 组织对话与学习状态变更。模型输出包含面向口语播报的 `speech`、面向屏幕展示的 `display`、状态更新 `state_patch` 和界面提示 `ui_hints`。服务端规范化输出并将学习状态写入用户档案，后续训练可再利用这些状态。

### 4.2 工具调用与检索

`server/src/tools.js` 提供教学知识库检索、歌曲检索和用户词汇查询等工具。Agent 可按学习意图进行工具调用，并限制循环轮数。知识检索优先使用向量索引，在向量能力不可用时可退回关键词检索；工具层失败不应阻断一般对话。

### 4.3 语音与多端适配

网页版优先采用浏览器 Web Speech API 的合适本地音色；本地语音不可用时调用服务端 `/api/tts`。服务端优先 Edge-TTS，随后尝试已配置的 OpenAI 兼容云 TTS，macOS 环境还可使用系统 `say` 作为兜底。小程序通过后端 TTS 接口合成音频，再写入临时文件播放。ASR 由服务端统一处理。

### 4.4 学习评估的证据约束

能力维度与总体分数来自实际对话、纠错或跟读记录；没有足够证据时显示“待评估”，不生成虚构分数。用户自述等级与系统评估结果区分展示，中文对话不作为韩语能力证据。

## 5. 技术架构

```text
Vue 3 网页版 ─┐
              ├─ HTTP / SSE ─ Express API ─ Agent 编排 ─ LLM / VLM / ASR / TTS
微信小程序 ───┘                         ├─ RAG 知识检索
                                        ├─ 教学与歌曲工具
                                        └─ JSON 用户档案与复习状态
```

| 层 | 技术与职责 |
|---|---|
| 网页端 | Vue 3、Vite、Pinia、Vue Router；负责登录、对话、训练和数据展示 |
| 小程序端 | 微信原生框架；复用后端 API 与学习流程 |
| 服务端 | Node.js、Express、openai SDK；统一处理模型、媒体、学习状态和账户接口 |
| 数据 | 用户档案以 JSON 文件保存；项目不依赖数据库服务 |
| AI 能力 | OpenAI 兼容接口；LLM、图像理解、ASR、TTS 可按需配置 |
| 语音实现 | Edge-TTS 默认免费合成；网页版额外尝试本地浏览器音色 |

核心代码入口：`server/src/index.js`（HTTP API）、`server/src/agent.js`（智能体与状态闭环）、`server/src/tools.js`（工具调用）、`server/src/knowledge.js`（RAG）、`server/src/store.js`（数据存储）、`server/src/system-prompt.js`（教学规则）、`web/src/pages/`（网页功能页）、`miniprogram/pages/`（小程序页面）。

## 6. 运行和复现

环境要求：Node.js 18 或更高版本、npm。无需数据库。详细步骤和完整环境变量说明以仓库根目录 `README.md` 与 `server/.env.example` 为准。

```bash
cd server
cp .env.example .env
npm install
npm start
```

另开终端启动网页版：

```bash
cd web
npm install
npm run dev
```

本地开发模式下，Vite 将 API 请求代理到 `localhost:3000`。没有配置 `LLM_API_KEY` 时可使用演示模式；真实 AI 能力需配置对应服务的 Key。不要将 `.env`、真实密钥、个人语音或含个人信息的教材图片提交到公开仓库或录屏。

## 7. 质量、边界与安全

- 用户档案按用户标识隔离；服务端提供注册登录、令牌校验和资料重置等接口。
- 图片上传经过媒体归一化；PDF/Word 文件当前不支持，教材内容需以图片形式提供。
- ASR、VLM 和云端 TTS 依赖外部服务配置与网络可用性；模型结果需要人工核对，尤其是低清教材 OCR 和自动发音评分。
- Edge-TTS 也需要服务端可访问其上游服务；网页本地语音音色依赖浏览器和操作系统，设备间音色可能不同。
- 正式部署时，服务端应运行在支持 Node.js 的主机；小程序需配置 HTTPS 合法域名与隐私权限说明。
- 录屏、演示账号及提交仓库不得包含真实 API Key、个人档案或未经授权的教材资料。
