# 项目导览 · 大白话版

> 这份文档不讲面试、不布置作业，只回答两个问题：
> ① 这个项目是怎么转起来的？② 那些专业名词到底是什么意思？
> 每个名词后面都标了它在项目里的"案发现场"，想看实物就顺着文件路径去找。

---

## 一、这个项目是什么（三句话）

1. 一个**韩语学习陪聊应用**：你跟 AI 老师用中文/韩文对话，它教你、纠错、记你的生词、安排复习。
2. 它有两个"壳"：**网页版**（Vue 写的，浏览器打开）和**微信小程序版**——两个壳共用同一个"大脑"。
3. 大脑 = 你自己的 **Node 后端**（负责记账、调度）+ **智谱 GLM 大模型**（负责真正说话、认图、听声音、发声）。

## 二、一次对话的完整旅程（核心必读）

场景：你在网页聊天框输入 `안녕하세요, 오늘 날씨 어때요?`，点发送。接下来 3 秒内发生了这些事：

```
 你的浏览器                  你家里的后端(:3010)                智谱云
┌───────────┐   发请求    ┌───────────────────┐   API调用   ┌──────────┐
│ Chat.vue  │ ─────────→ │ index.js 先验票     │ ─────────→ │ GLM 大模型 │
│ （界面）    │ ←───────── │ agent.js 教学主管    │ ←───────── │ 一滴滴吐字  │
└───────────┘ 一滴滴流回   │ llm.js 排队+重试     │            └──────────┘
      ↑ 韩文变语音          │ store.js 学习档案    │
      └──────────────────┴───────────────────┘
```

**第 1 步 · 前端打包请求**（`web/src/api/stream.js`）
你点发送，浏览器不是只把一句话发出去，而是一个"包裹"：说了什么、用的哪个人设、什么模式，还有你的**令牌**（证明"我是登录过的那个人"）。包裹用 **HTTP 协议**寄出，寄往后端的 `/api/chat/stream` 这个**接口**。

**第 2 步 · 到达后端，先过安检**（`server/src/index.js` + `auth.js`）
后端大门口有个保安叫**中间件**，每个请求进门都要被拦下查一次令牌——就像游乐园检票，手环（token）没过期才放行。放行后，前台（路由）根据地址把包裹转交给对应的处理人。

**第 3 步 · 教学主管接单，先翻你档案**（`server/src/agent.js`）
处理对话的是 agent.js。它先去档案室（`store.js`，其实是几个 JSON 文件）读你的学习状态：现在什么水平、生词本里有哪些词、最近老犯什么错。

**第 4 步 · 给 AI 派角色**（`server/src/system-prompt.js`）
大模型本身是"白纸"，需要一段**提示词（prompt）**告诉它："你是一位韩语老师，学生现在 N 水平，生词本里有 XX，最近错过 XX，请用这种方式教学"。agent.js 把你刚读到的档案**动态塞进**这段提示词——所以同一个 AI，对不同学生表现不同，秘密全在这。

**第 5 步 · 调用 AI**（`server/src/llm.js`）
llm.js 是"AI 联络员"：请求太多时先**排队**（并发限制，最多同时 2 个），失败了自动**重试**，然后带着完整提示词去智谱云调 `glm-4.5-flash` 模型，并且开着"**流式**"开关——要求 AI 别想完再一口气说，而是一边想一边吐字。

**第 6 步 · AI 吐字，后端转发**
AI 每吐一小段，后端立刻包成一个小帧 `data: {"t":"안녕"}` 推回浏览器——这个持续滴水的传输方式叫 **SSE**。

**第 7 步 · 前端打字机效果**（`web/src/api/stream.js`）
浏览器端有个循环在不停"接水滴"：接到一帧就解析出文字，追加到聊天气泡里——这就是你看到的**打字机效果**。顺便做容错：连接断了就自动**降级**成一次性普通请求重发（宁可慢，不能白屏）。

**第 8 步 · 收尾：批作业 + 记账**（`agent.js` → `store.js`）
AI 不只回话，还会按约定格式返回**结构化 JSON**：本次出现了哪些生词、你犯了哪些错。agent.js 解析出来，写回你的档案——所以下次对话它"还记得你"。**AI 本身什么都不记得，记忆全靠后端每次把档案重新塞给它。**

**第 9 步 · 点小喇叭，韩文变语音**（`web/src/api/tts.js` → `/api/tts`）
前端把文字发给后端，后端调 **Edge-TTS**（微软免费的语音合成）：韩文段用韩国声线、中文段用中国声线，分段合成后拼成一条音频发回来播放。

## 三、名词翻译表

### 基础概念

| 名词 | 大白话 | 在本项目哪里 |
|---|---|---|
| 前端 / 后端 | 前端＝店面（你看到的界面）；后端＝后厨（真正干活的电脑程序） | `web/` 与 `server/` |
| 前后端分离 | 店面和后厨是两个独立程序，靠"传纸条"合作 | 部署时前端和后端分开上线 |

| 端口 / localhost | 一台电脑像一栋楼，端口是房间号；localhost=本机，3010 是本项目后端的房间 | `http://localhost:3010` |

### 网页学习区与 3D 交互

网页版课程区（`web/src/pages/Course.vue`）有 A1、A2、B1 三个级别、18 个单元和 54 节课。Three.js 把当前级别的 6 个单元放进一座纸雕韩屋学习庭院：拖动可环视，滚轮或双指可缩放，点立体课程卡打开课时列表；已完成度会显示在站点外圈，级别仍按前一阶段单元进度解锁。相比早期密集的首尔地图，新场景一次只表达一条学习路线。

练习页（`Practice.vue`）用可翻面的厚纸卡做单词自评，语法和听力答题后即时展示解析或原文；口语页能播放韩语示范、录音、显示实时波形、评分与回放。浏览器没有麦克风时会给出演示评分流程。进度页（`Progress.vue`）把等级奖章做成可拖动查看的学习通行证，旁边记录四项能力均分、雷达图、12 周学习热力图、连续天数、XP 和单元完成度。

首页的 `EditorialCover3D.vue` 是一张可拖动的立体学习海报，使用原创纸雕韩屋静物图；登录页使用原创首尔城市摄影，素材均在 `web/public/images/` 本地打包。登录或注册成功后先翻开带用户名的学习期刊，再进入首页。Three.js 通过动态导入按需加载，庭院离屏或页面隐藏时暂停渲染；WebGL 创建失败时课程路线保留单元列表与静态图片，单词卡与等级通行证显示普通 HTML 降级视图。用户开启系统“减少动态效果”时关闭自动动效并直接切页。

网页版统一改成暖纸底色、墨色文字和赭金强调色。聊天页也沿用这套杂志排版：顶部刊头标识对话期号，模式改为下划线页签，消息与底部输入/导航共用全屏纸面；登录成功的翻刊过场与系统“减少动态效果”设置保持一致。

课程练习的结算请求失败时，`web/src/api/course.js` 会把练习记录放入浏览器 `localStorage` 的离线队列（最多保留 50 条），所以当前设备上的练习不会因短时断网而丢失。重新打开已登录网页、网络恢复，或之后成功提交一条进度时，程序会依序尝试补报；服务端返回登录失效时，队列会保留待重试。结算页会提示“已离线保存，联网后自动同步”。

### 登录与安全

| 名词 | 大白话 | 在本项目哪里 |
|---|---|---|
| 注册 / 登录 | 注册=建档；登录=每次出示身份证换通行证 | `auth.js` |
| 令牌（token） | 游乐场手环：登录一次，之后每个请求出示它即可，不用反复输密码 | `signToken()` |
| Bearer | 令牌的"出示姿势"：请求头里写 `Authorization: Bearer 手环码` | `auth.js` 的 `resolveAuth` |
| HMAC 签名 | 防伪钢印：后端拿只有自己知道的密钥给令牌盖章，伪造不出章=假票 | `verifyToken()` |
| 过期时间 | 手环上印的有效期，30 天后自动作废 | `TOKEN_TTL_MS` |
| 哈希 | 绞肉机：密码搅碎成一串乱码存起来；能验证"是不是原密码"，但搅碎的拼不回原密码 | `hashPassword()` |
| 加盐（salt） | 每个用户绞肉前撒不同的调料，两个用户设同样密码，存出来的乱码也不同，防"彩虹表"对照破解 | `scryptSync(password, salt)` |
| 时序攻击 | 高级小偷靠"服务器比对密码用时长短"偷信息；`timingSafeEqual` 让比对永远耗时一样 | `verifyPassword()` |

### 流式与实时

| 名词 | 大白话 | 在本项目哪里 |
|---|---|---|
| 流式（streaming） | 水管持续出水，而不是攒满一桶再给你 | `llm.js` 的 `chatStream` |
| SSE | 基于 HTTP 的"持续滴水"协议，格式是 `data: 内容\n\n` 一帧帧推 | `/api/chat/stream` |
| 打字机效果 | 前端接一滴水显示一个字的视觉效果 | `stream.js` 的 `reader.read()` 循环 |
| 降级（fallback） | 主路断了走备路：流式失败自动改用一次性请求 | `stream.js` 的 `fallback()` |
| AbortController | 浏览器的"挂断电话"按钮：用户点停止生成就中断请求 | `stream.js` 的 `abort()` |
| 离线进度队列 | 网络不通时先把课程结算暂存在本机，恢复后再补交 | `web/src/api/course.js` 的 `kfp_progress_queue` |

| 名词 | 大白话 | 在本项目哪里 |
|---|---|---|
| LLM | 大语言模型：会聊天写字的“大脑”，本项目默认用 `glm-4.7-flash` | `llm.js` 的 `LLM` |

### 部署（怎么让别人访问到）

| 名词 | 大白话 | 在本项目哪里 |
|---|---|---|
| 部署 | 把程序从"只有你能访问"变成"全世界能访问" | `DEPLOY.md` |
| Cloudflare Workers | 别人家免费机房：本项目把网页"成品"（`dist/` 静态文件）寄存在那 | `web/wrangler.*` |
| 静态托管 | 只放现成文件（HTML/CSS/JS），不能跑后厨程序 | Workers 只托管前端 |
| 内网穿透（tunnel） | 你家电脑没公网门牌，用一根"隧道"把外网流量引进来 | `cloudflared`，后端在 Mac:3010 |
| 同源 | 让网页和它的后端看起来是一家的，浏览器就不闹 CORS 脾气 | 部署自愈脚本里做的适配 |

                          cloudflared 隧道把家里 Mac:3010 的后厨接上外网

## 五、以后想深学时的入口（先记一句就够）

想深入时从 **`server/src/auth.js`**（190 行、最独立、知识点最密集）开始精读，再按 `index.js → llm.js → agent.js` 的顺序推进；前端最后。深度学习计划已备好，随时可重启。
